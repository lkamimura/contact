# Drone Contact Page

Este proyecto es una página web de contacto diseñada específicamente para un ingeniero aeronáutico especializado en drones y control de vehículos. La página permite a los visitantes enviar consultas a través de un formulario de contacto.

## Estructura del Proyecto

El proyecto tiene la siguiente estructura de archivos:

```
drone-contact-page
├── src
│   ├── index.html         # Página principal del sitio web
│   ├── contact.html       # Página de contacto con formulario
│   ├── components
│   │   ├── header.html    # Encabezado del sitio web
│   │   └── footer.html    # Pie de página del sitio web
│   ├── css
│   │   └── styles.css     # Estilos CSS para el diseño
│   └── js
│       └── main.js        # Código JavaScript para interactividad
├── package.json           # Archivo de configuración para npm
├── .gitignore             # Archivos y carpetas a ignorar por Git
└── README.md              # Documentación del proyecto
```

## Instalación

Para instalar las dependencias del proyecto, ejecute el siguiente comando en la raíz del proyecto:

```
npm install
```

## Ejecución

Para ejecutar el sitio web, simplemente abra el archivo `src/index.html` en su navegador web.
